## 运行命令

命令可用通过 Win+R 运行，也可以在文件管理器地址栏或终端中执行，示例
- 快捷方式：位置 `explorer.exe ms-settings:命令`
- 命令行：`start ms-settings:命令`
- html 链接：`<a href=ms-settings:命令>点击内容</a>`
- 商店应用：Win + R 运行 `ms-windows-store://pdp/?productid=9nblggh4nns1`（`pid`后面的号码可在[商店](https://apps.microsoft.com)指定应用地址栏找到
