## 快捷键

### 标签和窗口

| 快捷键 | 说明 |
|--------|------|
| Ctrl + N | 打开新窗口 |
| Ctrl + Shift + N | 在无痕模式下打开新窗口 |
| Ctrl + T | 打开并跳转到新的标签页 |
| Ctrl + Shift + T | 重新打开并跳转到最后关闭的标签页 |
| Ctrl + Tab 或 Ctrl + PgDn | 跳转到下一个标签页 |
| Ctrl + Shift + Tab 或 Ctrl + PgUp | 跳转到上一个标签页 |
| Ctrl + 1 ~ 8 | 跳转到特定标签页（第1~8个） |
| Ctrl + 9 | 跳转到最后一个标签页 |
| Alt + Home | 在当前标签页中打开主页 |
| Alt + ← / → | 后退/前进到一个页面 |
| Ctrl + W 或 Ctrl + F4 | 关闭当前标签页 |
| Alt + 空格键 + N | 最小化当前窗口 |
| Alt + 空格键 + X | 最大化当前窗口 |
| Alt + F4 | 关闭当前窗口 |

### 功能

| 快捷键 | 说明 |
|--------|------|
| Alt + F、Alt + E、F10 | 打开 Chrome 菜单 |
| Ctrl + Shift + B | 显示或隐藏书签栏 |
| Ctrl + Shift + O | 打开书签管理器 |
| Ctrl + H | 打开历史记录 |
| Ctrl + J | 打开下载内容 |
| Shift + Esc | 打开 Chrome 任务管理器 |
| F6（反向 Shift + F6） | 在地址栏、书签栏和页面内容之间切换焦点 |
| Ctrl + F 或 F3 | 打开查找当前页 |
| Ctrl + G | 跳转到查找栏中匹配的下一条内容 |
| Ctrl + Shift + G | 跳转到查找栏中匹配的上一条内容 |
| F12 或 Ctrl + Shift + J | 打开开发者工具 |
| Ctrl + Shift + Delete | 打开清除浏览数据选项 |
| Ctrl + Shift + M | 使用其他帐号登录或以访客身份浏览 |
| Alt + Shift + I | 打开反馈表单 |

### 地址栏

| 快捷键 | 说明 |
|--------|------|
| Enter | 使用默认搜索引擎搜索关键字 |
| 输入搜索引擎名称 + Tab 或 Space | 使用其他搜索引擎搜索 |
| Ctrl + Enter | 添加 www. .com 并打开 |
| Alt + Enter | 打开新标签页并用默认搜索引擎搜索 |
| Alt + D 或 F6 | 跳转到地址栏 |
| Ctrl + K 或 Ctrl + E | 从页面中的任意位置搜索 |
| Shift + Delete | 从地址栏中移除联想查询内容 |

### 网页

| 快捷键 | 说明 |
|--------|------|
| Ctrl + P | 打印当前页 |
| Ctrl + S | 保存当前页 |
| F5 或 Ctrl + R | 重新加载当前网页 |
| Shift + F5 或 Ctrl + Shift + R | 重新加载当前网页（忽略缓存） |
| Esc | 停止加载网页 |
| Tab（反向 Shift + Tab） | 浏览下一个可点击项 |
| Ctrl + O | 使用 Chrome 打开计算机中的文件 |
| Ctrl + U | 显示当前网页的 HTML 源代码 |
| Ctrl + D | 添加到书签 |
| Ctrl + Shift + D | 将所有打开的标签页保存在书签的新文件夹中 |
| F11 | 全屏模式 |
| Ctrl + + / - | 放大/缩小显示比例 |
| Ctrl + 0 | 恢复默认显示比例为 100% |
| Space 或 PgDn（反向加 Shift） | 向下滚动页面 |
| Home / End | 回到页面顶部/底部 |
| 按住 Shift + 滚动鼠标滚轮 | 在网页上水平滚动 |
| Ctrl + ← / → | 将光标移到文本字段中的上一个/下一个字词前面 |
| Ctrl + Backspace | 删除文本字段中的上一个字词 |
| Alt + N | 将焦点移到通知上 |
| Alt + Shift + A / D | 在通知中允许/拒绝 |

### 鼠标操作

| 快捷键/操作方式 | 说明 |
|----------------|------|
| 将链接拖到标签页中 | 在当前标签页中打开链接 |
| 按住 Ctrl + 点击链接 | 在新的后台标签页中打开链接 |
| 按住 Ctrl + Shift + 点击链接 | 打开链接并跳转到该链接 |
| 将链接拖到标签栏的空白区域 | 打开链接并跳转到该链接 |
| 按住 Shift + 点击链接 | 在新窗口中打开链接 |
| 将标签页拖出标签栏 | 在新窗口中打开标签页 |
| 将标签页拖到现有窗口中 | 将标签页移至当前窗口 |
| 拖动标签页的同时按 Esc | 将标签页移回其原始位置 |
| 拖动到书签栏中 | 将当前网页保存为书签 |
| 按住 Alt + 点击链接 | 下载链接目标 |
| 右键点击或左键按住 ← / → | 显示浏览记录 |
| 双击标签栏的空白处 | 在最大化和窗口之间切换 |
| 按住 Ctrl + 向上/向下滚动鼠标 | 放大/缩小显示比例 |
