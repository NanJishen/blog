使用方法：安装 pip install -U yt-dlp；启动 python ytdl_server.py；打开 极限工具·视频下载，粘贴链接后点右侧解析或按 Ctrl+Enter，解析完成后下载

页面功能：支持多个链接，也支持抖音、小红书的整段分享文字，链接会自动提取，
每条结果有封面、标题、作者、时长，画质可选（最高画质、各分辨率、仅音频），多条时有「全部下载」。
下载服务地址默认 127.0.0.1:8765，可以改，会记住；页面没连上服务时会提示怎么启动。
辅助程序只放行这六个平台的链接，b23.tv、v.douyin.com、xhslink.com 这类短链会自动展开。

注意事项：

ffmpeg：建议装好并加入 PATH。没有它，YouTube 和 B 站的高画质（音视频分离）下载不了，转 MP3 也不行，只能下到较低画质的合一流。
抖音、小红书、微博：经常要登录状态才能解析，可以用 python ytdl_server.py --browser edge 借用浏览器的 cookies，或者用 --cookies cookies.txt。这几个平台的接口变动很快，解析失败时先执行 pip install -U yt-dlp 更新。
局域网访问：如果 devbox 是通过局域网地址打开的，辅助程序要用 --host 0.0.0.0 启动，并把页面里的服务地址改成那台机器的 IP。
代理：需要代理的话加 --proxy http://127.0.0.1:7890。
