使用帮助

便笺

  • 顶栏 + 或双击浮动区新建便笺
  • 拖动标题栏移动，拖动右下角缩放（双击自动大小）；双击标题栏添加或修改标题，点标题栏的 □ 按钮最大化/还原
  • 右键标题栏弹出菜单可复制内容，右键 × 号可锁定/解锁
  • 点击标题栏的−号可收进顶栏的“稍后”文件夹，点文件夹可取回
  • 以 ```bash 或 ```json 开头、``` 结尾是代码块
  • 便笺内支持直接粘贴图片，但需先授权目录；图片显示在文字下方，点击可放大，删掉文字里的 ![](文件名) 那一行就移除图片

整理与背景

  • 网格图标是自动排列：每点一次，在“整齐排列→横向满高→四宫格铺满→还原位置”之间循环（横向满高：一行最多 4 列，超过 4 个换到下一行，铺满整个窗口）
  • 叠层图标是切换背景：每点一次，切换背景效果（包括已添加的背景图片）
  • 左上角汉堡菜单 → 主题设置：切换主题（Tech / Aura / Gruvbox），调整便笺内字号和透明度，选择浮动区背景或添加本地图片作背景
  • 顶栏闹钟图标 → 计时器：倒计时、闹钟、秒表；可拖动标题栏移动，时间到会响铃并弹出提醒。闹钟页点 + 添加，点时间改时间、点描述改描述（闹钟需要页面一直开着）

标注

  • 铅笔图标是标注工具：菜单里是工具、粗细滑杆和颜色；滚轮也能调粗细或字号，方形或圆形按住 Shift 可画正方/正圆
  • 第一个是选择工具：点一条标注或在空白处拖出框来框选（按住 Shift 加选 / 取消），拖动移动，拖端点调整，滑杆和颜色改粗细、颜色，Delete 删除；没选工具时标注不会被选中
  • 文字工具：点空白处新建文字，点已有文字进入编辑，Enter 确认、Shift+Enter 换行
  • 工具使用期间菜单一直保留，Esc、右键或再点一次当前工具退出后才收起

同步与备份

  • 右上角链接图标：选择并授权文件夹，之后每条便笺实时保存为“标题.md”（没有标题的用编号，如 3.md；重名的加“-编号”；单向写入）
  • 删除的便笺会保存到该文件夹的 trash 子目录（标题-日期-时间.md），需要时可手动找回
  • 该文件夹里的 kanban-backup.json 是全部数据（便笺、标注、倒数日、代办、闹钟、主题设置）的实时备份，backup/ 里保留最近 30 份历史快照；浏览器数据被清空后，重新授权该文件夹即可恢复
  • 删除便笺会删掉对应文件，但图片会保留
  • 左上角汉堡菜单：导出/导入备份（含标注、倒数日和代办），导出图片（截图）

倒数日

  • 点击右上角清单图标弹出代办侧边栏：点 + 添加，点条目修改内容（Enter 保存，Shift+Enter 换行），按住条目拖动排序，点 × 删除；右键便笺标题栏选“代办”，便笺会变成一条代办（可撤销）
  • 点击右上角日历图标弹出倒数日侧边栏：点 + 添加，点日期选择到期日；点图钉固定，固定后点击浮动区不会自动收回（再点一次取消，Esc 或再点日历图标收起）
  • 默认最上的一条最快到期，右键收回按钮可固定侧边栏
