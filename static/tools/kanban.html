使用帮助

便笺

  • 顶栏 + 或双击浮动区新建看半条
  • 拖动标题栏移动，拖动右下角缩放（双击自动大小），双击标题栏最大化/还原
  • 右键标题栏弹出菜单可复制内容，右键 × 号可锁定/解锁
  • 点击标题栏的−号可收进顶栏的“稍后”文件夹，点文件夹可取回
  • 以 ```bash 或 ```json 开头、``` 结尾是代码块
  • 便笺内支持也直接粘贴图片，但需先授权目录

整理与背景

  • 网格图标是自动排列：每点一次，在“整齐排列→四宫格铺满→还原位置”之间循环
  • 叠层图标是切换背景：每点一次，切换背景效果

标注

  • 铅笔图标是标注工具：滚轮调粗细或字号，方形或圆形按住 Shift 可画正方/正圆
  • Esc 或右键退出工具；没选工具时点一条标注为选中，按 Delete 删除

同步与备份

  • 右上角链接图标：选择并授权文件夹，之后每条便笺实时保存为 N.txt（单向写入）
  • 删除便笺会删掉对应文件，但图片会保留
  • 左上角汉堡菜单：导出/导入备份（含标注和倒数日），导出图片（截图）

倒数日

  • 点击右上角日历图标弹出倒数日侧边栏：点 + 添加，点日期选择到期日
  • 默认最上的一条最快到期，右键收回按钮可固定侧边栏
