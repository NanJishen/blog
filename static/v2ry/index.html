  • 解压后，启动其中的 V2ray.exe 然后如下图顺序操作 ↓

安卓手机使用方法

> 点此下载客户端
  • 启动 v2rayNG ，点击右上角+号，扫描二维码或导入链接（问群主要），最后点击右下角启动

  • 日后更新列表规则，点左上角菜单，选资源文件，点右上角云图标更新

苹果 MacOS 和 Linux 系统

> 点此下载客户端


Linux 和 MacOS 使用方法：解压并放到你指定的目录中，打开终端并执行命令
bash 
# 赋予执行权限
chmod +x v2rayN
# 启动程序
./v2rayN
注意：需 macOS 11+ 系统版本及以上

小火箭

先用美区账号登陆苹果商店，才可以下载 Shadowrocket 应用
  • 启动 Shadowrocket 应用，点击右上角的 + 号

  • 类型选【Subscribe】，在 URL 栏中粘贴订阅地址（和群主要），在下方备注一个分组名，最后点击右上角的完成
  • 回到 Shadowrocket 首页即可看到节点信息
  • 进入配置选项页，选择默认配置文件即可
  • 进入设置页，按照下图将订阅设置项的“打开时更新”和“自动后台更新”选项同时开启
  • 回到首页点击上方全局路由可以更改代理模式
